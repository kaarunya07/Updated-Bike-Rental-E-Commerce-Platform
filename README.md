# Updated-Bike-Rental-E-Commerce-Platform
The Bike Rental Management System is a Java-based desktop application designed to digitize and simplify the bike rental process. It allows users to view available bikes, calculate rental costs, book bikes, and manage bookings through an intuitive graphical user interface built using Java Swing. The system replaces traditional manual rental methods with a structured, efficient, and user-friendly solution.

This project follows Object-Oriented Programming (OOP) principles such as inheritance, interfaces, and modular class design to ensure scalability and maintainability.


**Key Features**

--> View all available bikes with real-time availability status

--> Calculate rental cost based on duration

--> Customer booking with name and rental hours

--> Cancel bookings and update availability instantly

--> Clean and improved Swing-based UI

--> Modular OOP design using interfaces and inheritance
